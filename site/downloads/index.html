推荐

桌面安装器

安装到系统路径，附 Pax 图标。当前未做商业签名：Windows SmartScreen / macOS Gatekeeper 可能提示。

🐧

Debian / Ubuntu

x86_64 · .deb

适用于 Debian、Ubuntu 及其衍生发行版；安装到 /usr/bin/poly。

下载 .deb (x86_64)
bash
sudo dpkg -i polypack-cli_1.16.0_amd64.deb
poly --version
🐧

AppImage

x86_64 · .AppImage

无需安装，chmod +x 后直接运行；适合任意现代 Linux 发行版。

下载 AppImage
bash
chmod +x poly-1.16.0-x86_64.AppImage
./poly-1.16.0-x86_64.AppImage --version
🪟

Windows

x86_64 · .msi

安装到 Program Files\PolyPack 并加入 PATH；支持静默安装 / 卸载。

下载 .msi
PowerShell
msiexec /i poly-1.16.0-x86_64.msi
poly --version
🍎

macOS

Apple Silicon · .pkg

安装到 /usr/local/bin/poly；未签名，首次运行可能需在“隐私与安全性”允许。

下载 .pkg (arm64)
bash
sudo installer -pkg poly-1.16.0-aarch64.pkg -target /
poly --version

校验

下载后先校验

Linux / macOS
sha256sum --check --ignore-missing SHA256SUMS.txt
# macOS:
shasum -a 256 -c SHA256SUMS.txt
Windows PowerShell
Get-FileHash .\\poly-1.16.0-x86_64.msi -Algorithm SHA256
# compare with the matching line in SHA256SUMS.txt

校验和只能证明文件与发布清单一致，不能证明发布者身份；正式签名 / 公证需维护者配置证书。

要求

系统要求

Linux

x86_64，glibc 2.39+（release 在 ubuntu-latest 构建）；deb 或 AppImage。

Windows

Windows 10/11 x86_64；MSI 需要管理员权限写入 Program Files 与系统 PATH。

macOS

Apple Silicon（arm64），macOS 12+；pkg 安装到 /usr/local/bin。
