项目介绍

一个核心，交付所有端

PolyPack 用一条声明式流水线把 Rust 业务核心与 React UI 适配层带到桌面、移动端、小程序、TV、穿戴和嵌入式平台。每个产物都有可复现构建、结构校验、签名与可选的 SBOM。

为什么是 PolyPack

一套配置、一条 DAG、一个回执格式。目标由 TargetSpec 描述，打包器通过 ProviderRegistry 统一装配；内建目标与第三方插件走同一条沙箱与签名链。

从 v1.0 到 v1.15：49 个目标、插件沙箱、农场 v1、签名发布、SBOM、OTA、设备预览与签名插件索引都已落地。

能力

为真实发布而设计

不是又一个脚手架，而是从构建、校验、签名、发布到热更的完整链路。

49 个目标

可验证流水线

结构校验、可复现构建、产物摘要、SBOM 与签名回执在同一条 DAG 内完成。

增量发布

poly release --changed 用内容摘要跳过未变化目标；五目标实测后端调用 5→1。

安装

三条路径，选一条

预编译二进制适合大多数用户；需要参与开发或自定义目标时从源码构建。

bash · release v1.15.0
curl -fsSL https://raw.githubusercontent.com/erikwang2013/polypack/v1.15.0/scripts/install.sh | bash
poly --version

强制 SHA-256 校验；配置 MINISIGN 公钥后可启用严格签名验证。

PowerShell
# Download poly-x86_64-pc-windows-msvc.zip from the release page,
# verify SHA256SUMS.txt, then add poly.exe to PATH.
poly --version
bash
git clone https://github.com/erikwang2013/polypack
cd polypack
cargo install --path crates/poly-cli
poly doctor

需要一个可用的 Rust 工具链（MSRV 1.98）。完整说明见 docs/INSTALL。

使用说明

从初始化到发布

poly init / build
poly init my-app
cd my-app
poly doctor
poly build --target web
poly verify / release
poly verify --reproducible
poly verify --sbom --target web
poly release --changed --target linux,web \
  --repo .polypack/repo --credential env:RELEASE_GPG_KEY
poly plugin
poly plugin new my-target
poly plugin check my-target
poly plugin add my-plugin --index ./index.json \
  --trust-root env:INDEX_KEY --publisher-key env:PUBLISHER_KEY
poly plugin search my-plugin --index ./index.json \
  --trust-root env:INDEX_KEY --revocations-trust-root env:REVOCATION_KEY
history / update / preview
poly history --target web --limit 10
poly update manifest --channel stable --version 1.2.3 \
  --platform windows-x86_64 --artifact app.nsis.zip --base-url https://updates.example.com
poly preview --dry-run --target android --device android-phone
